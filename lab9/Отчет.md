## ВВЕДЕНИЕ

### Общая цель проекта

Разработка и тестирование системы управления компанией с применением:
- **ООП принципы** (инкапсуляция, наследование, полиморфизм, композиция)
- **Паттерны проектирования** (Decorator, Adapter, Facade, Factory, Singleton, Builder, Strategy, Observer, Command)
- **Рефакторинг** для улучшения качества кода
- **Комплексное тестирование** для обеспечения надежности

- **Python 3.8+** — основной язык программирования
- **pytest** — фреймворк для модульного тестирования
- **pytest-cov** — измерение покрытия кода
- **unittest.mock** — создание mock-объектов
- **JSON/CSV** — форматы сохранения и экспорта данных

```yaml
# .github/workflows/tests.yml
name: Test Suite

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: [3.8, 3.9, 3.10, 3.11]
    
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-python@v2
        with:
          python-version: ${{ matrix.python-version }}
      
      - name: Install dependencies
        run: |
          pip install pytest pytest-cov pytest-xdist
      
      - name: Run tests
        run: |
          pytest tests/ -v --cov=src --cov-report=xml
      
      - name: Upload coverage
        uses: codecov/codecov-action@v2
```

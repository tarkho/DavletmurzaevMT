## Теоретическая часть

Git — распределённая система контроля версий, предназначенная для отслеживания изменений
в исходном коде, хранения истории разработки и организации совместной работы над
проектами.

GitHub — веб-сервис для размещения Git-репозиториев и совместной разработки программного
обеспечения.

Основные понятия Git:
- **Репозиторий** — хранилище проекта и истории его изменений
- **Коммит** — фиксация изменений в репозитории
- **Индекс (staging area)** — промежуточная область между рабочим каталогом и коммитом
- **Ветка (branch)** — независимая линия разработки
- **Удалённый репозиторий** — репозиторий, размещённый на сервере

Статусы файлов в Git:
- `untracked` — неотслеживаемые файлы
- `modified` — изменённые файлы
- `staged` — файлы, добавленные в индекс

Основные команды Git:
- `git init`
- `git status`
- `git add`
- `git commit`
- `git branch`
- `git checkout`
- `git merge`
- `git remote`
- `git push`
